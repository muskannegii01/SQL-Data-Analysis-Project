# Pizza Sales SQL Analysis

## Project Overview

This project analyzes pizza sales data using SQL and MySQL.

The analysis focuses on orders, pizzas, pizza types, and order details to understand sales patterns and identify useful business insights.

## Tools Used

- MySQL
- SQL
- GitHub

## Dataset

The project contains four datasets:

- orders
- order_details
- pizzas
- pizza_types

## Business Questions

The project answers different questions related to pizza sales, such as:

## Business Questions

1. What is the total number of orders placed?
2. What is the total revenue generated from pizza sales?
3. What is the highest-priced pizza?
4. What is the most common pizza size ordered?
5. What are the top 5 most ordered pizza types and their quantities?
6. What is the total quantity of each pizza category ordered?
7. What is the distribution of orders by hour of the day?
8. What is the category-wise distribution of pizzas?
9. What is the average number of pizzas ordered per day?
10. What are the top 3 most ordered pizza types based on revenue?
11. What is the percentage contribution of each pizza type to total revenue?
12. What is the cumulative revenue generated over time?
13. What are the top 3 most ordered pizza types based on revenue for each pizza category?

## SQL Analysis

SQL queries were used to:

- Filter and sort data
- Aggregate sales information
- Group data
- Use JOINs between tables
- Find top-selling pizzas
- Analyze order and sales patterns

## Project Files

- `orders` – Order information
- `order_details` – Details of each order
- `pizzas` – Pizza information
- `pizza_types` – Pizza type and category information
- `SQL_Data_Analysis.sql` – SQL queries used for the analysis

The key findings from the SQL analysis are based on the questions answered in the project.
